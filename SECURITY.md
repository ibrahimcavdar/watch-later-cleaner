# Security Policy

Do not include session cookies, authentication headers, account details, or private playlist data in an issue, screenshot, log, or pull request.

For a security-sensitive report, use GitHub's private vulnerability reporting feature once it is enabled for this repository. If private reporting is unavailable, open a minimal issue asking the maintainer for a private contact channel without disclosing the vulnerability.

The extension intentionally keeps authentication material in memory only. Changes that log, persist, expose, or transmit authentication data to any destination other than YouTube are not accepted.
